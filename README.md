# Smart Safety Helmet

## Description
Smart Safety Helmet is an IoT project designed to enhance worker safety in industrial and construction environments.

The helmet uses sensors to monitor environmental conditions and detect potential hazards. When a dangerous situation is detected, the system generates alerts to help prevent accidents.

## Features
- Real-time monitoring
- Hazard detection
- Safety alerts
- Worker protection

## Technologies Used
- esp32
- IoT Sensors
- python
- mobile application 

## Project Goal
The objective of this project is to improve workplace safety by providing intelligent monitoring and early warning capabilities.
